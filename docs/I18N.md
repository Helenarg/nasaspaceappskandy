# Language presentation

The app supports English, Sinhala and Tamil selection. Browser preferences persist in local storage and the HTML language follows both detected and explicitly selected preferences. Native font rendering is supported; persistent native language preferences are a separate future storage task.

## Translated interface

`src/i18n/strings.ts` contains keyed navigation and shared controls. `src/i18n/copy.ts` supplies presentation translations for the new homepage, all nine interior page titles and introductions, footer navigation, common form labels, registration tracks and common validation messages. `LocalizedText` applies these translations without changing the original form values or Firestore payload enums. Whitespace is normalized for lookup; missing copy remains readable in English.

Long event descriptions, workshop schedules, committee biographies, news articles, technical challenge briefs, sponsor claims and legal wording retain their existing source text. A full editorial translation of that content is not included. Proper names, NASA branding, image credits and data values remain intact.

## Typography and layout

- English retains Fira Sans and Overpass.
- Sinhala uses Noto Sans Sinhala Regular/Bold; Tamil uses Noto Sans Tamil Regular/Bold, bundled through Expo fonts.
- Indic text uses zero letter spacing, increased line-height and smaller display type at narrow widths. Whole lines are revealed; individual code points are never split for animation, preserving text shaping.
- Nested text inherits its parent type size and weight. Inputs use the matching script font.
- Sinhala/Tamil navigation uses the roomy drawer rather than squeezing eight longer labels into the English desktop link row. Full language names appear in the picker and its selected radio state is announced.
- Label text may wrap inside action buttons and form controls.

## Translation review

The Sinhala and Tamil wording is a first pass. Native-speaking organizers should review terminology and idiomatic phrasing before publication, including the preferred local words for hackathon and campus ambassador. This is a content review recommendation, not a request to block local development.

## Adding copy

For a shared keyed control, add the English key and corresponding translations in `strings.ts`. For existing literal presentation text, add its normalized English text and `[Sinhala, Tamil]` pair in `copy.ts` and render it using the shared `Text` primitive from `components/LocalizedText`. Keep server IDs, submission enums and user-entered values outside the presentation dictionary.
