# Languages

Sri Lanka has two official languages (Sinhala, Tamil) plus English as a link
language. The site ships a three-way switch in the navbar; the choice is stored per
browser and the `<html lang>` attribute follows it.

## What is translated today

`src/i18n/strings.ts` covers the shared chrome:

- navigation labels and the register CTA
- hero badge, both hero buttons, the three hero highlights
- footer column headings
- form status and validation messages

Any key missing from a dictionary falls back to English, so a partial translation
never shows a raw key or an empty label.

## What is NOT translated yet

All page body copy: about, events (schedule and workshops), challenges, ambassadors,
join, sponsors, news, register and contact. These are long, event-specific texts
that need the organising committee's own wording, not a machine translation.

## ⚠️ Review needed

The Sinhala and Tamil strings currently in `strings.ts` are a first pass and have
**not** been reviewed by a native speaker. Before launch, a Sinhala-speaking and a
Tamil-speaking member of the committee should read through that file and correct
them. Terms worth deciding deliberately:

- "Hackathon" — transliterate (හැකතන් / ஹக்கத்தான்) or keep the English word?
- "Ambassador" — තානාපති reads diplomatic; a campus-lead term may be better.
- Whether the event name "NASA Space Apps Challenge" stays in Latin script
  everywhere (recommended: yes, it is a trademark).

## Adding a translated page

1. Add keys to `en` in `src/i18n/strings.ts` (it is the source of truth and the
   type for every other dictionary).
2. Add the Sinhala and Tamil values.
3. In the page, `const { t } = useI18n();` and replace the literal with `t('key')`.

## Known limitations

- Language is per browser, not per URL. There are no `/si/` or `/ta/` routes, so
  search engines index the English version only. If the committee wants indexed
  translated pages, that is a routing change: `app/[lang]/…` plus `hreflang` tags.
- Native builds always start in English (no `expo-localization` dependency yet).
