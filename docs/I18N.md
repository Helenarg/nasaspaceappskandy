# Languages and presentation

English, Sinhala and Tamil are selected through accessible buttons. Web selection persists in localStorage and ?lang= URLs; the document language follows selection. Native selection uses SecureStore and falls back to Expo Localization. Delayed preference reads cannot overwrite newer explicit choices.

strings.ts supplies keyed shared controls. copy.ts combines its presentation dictionary with sinhala-copy.ts and tamil-copy.ts. Specialist reviews expanded complete sentences across pages, forms, validation, privacy and participation guidance. LocalizedText and LocalizedPressable translate visible copy and accessible labels. Payload enums and user input remain unchanged. Missing copy falls back to English, marked with its language for pronunciation.

English uses Fira Sans and Overpass. Sinhala/Tamil use corresponding Noto Sans regular/bold fonts. Imports specify individual weights to avoid exporting whole font families. Indic typography uses roomier line heights, zero letter spacing and whole-line animation. Translated navigation uses a drawer, and buttons permit wrapping.

Add normalized whole sentences to both dictionaries rather than joining fragments that assume English grammar. Keep source credits and server values unchanged. Run lint/typecheck and inspect long text on mobile. See the specialist reports in docs/reviews/post-fix/01-tamil.md and 02-sinhala.md. They are not native-speaker certification; organizers should review idiomatic terminology before publication.

Static HTML exports begin in English and hydrate to the requested language. Runtime metadata is localized; non-JavaScript crawlers/social bots receive the English export. Dedicated localized static routes and hreflang remain future SEO work.
